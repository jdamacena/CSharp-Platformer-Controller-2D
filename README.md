## C# Ultimate Platformer Controller 

This is a C# port of the [original](https://noasey.itch.io/ultimate-2d-platformer-controller) GDscript version of the plaformer controller script for GODOT.

This version makes it easier to work with C# in the GODOT engine, since mixing C# and GDScript is not so easy, I ported it to C# so I could more easily adapt it to my project.
I included a bare bones demo to help you get started.

### To use the code, just copy the player's script from the demo project and adapt it as needed or extend it via inheritance.

This port actually took me a bit of time and I'm still studying the code, so any contributions are welcome to make it more extinsible and to take better advantage of C#'s power. 

I hope this can help some people since it's been many hours poured into this code by me and the original developer that you don't have to!
